# Magic Editor X 2.5 security review: new surfaces

Scope: everything 2.5 adds or changes on top of 2.4.0 (`main` at 0e905d2): the entry panel with presence, soft lock and homepage widgets, local drafts and lazy start of fields, "Insert from another entry" and the block clipboard, palette colours, superscript/subscript and inline annotations, private upload providers and dropped files, the MCP tools, and the fixes of the six known 2.4 issues. Reviewed against the installed Strapi 5.61.1 source and the workbench security rules (route authz and RBAC, IDOR, mass assignment, input bounds, ReDoS, injection, SSRF, secrets, rate limits, privacy, logging, supply chain).

## Unchanged controls re-checked

RBAC on every new admin route (`admin::isAuthenticatedAdmin` + `admin::hasPermissions`; 7 new routes, one new action `mcp.use`, granted to no role automatically), strict bounded zod schemas, Content Manager access through `services/access.js` with 404 on denial, no content, tokens, URLs with queries or personal data in logs, outgoing requests only through `utils/url-security.js` (2.5 adds none), synthetic data in tests and screenshots. `npm audit --omit=dev`: 0 vulnerabilities; no new runtime dependency.

## Residual risks

- Presence rows of the entry panel count toward no socket limit; they are capped by the rate limit and their 30 s lifetime. A closed tab disappears after 30 s.
- Local drafts are unencrypted in the browser profile until save, discard, expiry or voluntary logout; a session that ends on its own keeps them on purpose. If Strapi renames its internal logout actions, logout stops clearing them and they still expire.
- An admin who can read an entry can copy its draft content through "Insert from another entry", the same as the Content Manager shows them.
- A signed URL works for anyone holding it until the provider's expiry. A file replaced in the Media Library keeps its old URL in plain output until the block's file is chosen again (`?mex=` resolves the new one). Content that reaches the editor unsigned loads once without a signature before it is swapped.
- A host's own annotation `resolve` decides its filters. Settings custom blocks with their own field rules drop colours inside their content.
