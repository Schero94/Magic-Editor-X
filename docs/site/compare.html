How Magic Editor X compares with other Strapi editors

Six ways to edit rich text in Strapi 5, compared feature by feature. Every claim about another product links to the page it comes from. Facts as of 2026-11, checked on 26 November 2026.

This page is written by the maintainer of Magic Editor X, so read it with that in mind. Where another editor is the better or simpler choice, it says so. If something here is wrong or out of date, open an issue and it gets fixed.

Which one to choose

Start from what your editors need, not from the longest feature list. Short answers:

  • Simple formatted text, nothing to install: Strapi's built-in Blocks field. It covers paragraphs, headings, lists, quotes, code and images, and Strapi publishes a React renderer for it.
  • Word-like editing and HTML output: CKEditor 5. The community plugin (@_sh/strapi-plugin-ckeditor) is free under GPL and self-hosted; the official plugin (@ckeditor/strapi-plugin-ckeditor) needs a CKEditor licence key. CKEditor tables can hold lists and headings in their cells and can be nested.
  • Keep the Strapi Blocks format, with more block types: Better Blocks (@qkix/strapi-plugin-better-blocks). It stores Blocks JSON plus its own node types and adds tables, callouts, math and diagrams.
  • ProseMirror JSON and your own React components: the Tiptap plugin by Notum (@notum-cz/strapi-plugin-tiptap-editor).
  • A team that already knows TinyMCE: the TinyMCE plugin by SKLINET (@sklinet/strapi-plugin-tinymce), with HTML output.
  • Several people editing the same entry, with comments, version history and AI on your own provider, all free: Magic Editor X (magic-editor-x), a block editor built on Editor.js.

Where the others are better or simpler

  • Strapi Blocks is the simplest choice. There is nothing to install or update, Strapi maintains it, and its JSON works with Strapi's own React renderer. If your editors write short, formatted text, a plugin adds more to maintain than it gives back.
  • CKEditor is the closest to Word. It is a classic rich text editor with HTML output, and its table cells can hold lists, headings and even other tables (CKEditor tables). Magic Editor X table cells hold inline text only. The community CKEditor plugin is also by far the most used of the plugins here (see adoption).
  • Better Blocks keeps the Strapi Blocks format. Content stays Blocks JSON, so you do not have to migrate existing fields or change how your site reads them. Magic Editor X stores Editor.js JSON and converts Blocks fields with a one-way migration command.
  • Tiptap gives you ProseMirror JSON. The Notum plugin lets you register your own components with their own forms and render the same JSON with Tiptap on your site, which suits teams that already build with Tiptap.
  • CKEditor and TinyMCE are backed by companies. Both sell collaboration, track changes and AI with support contracts (CKEditor pricing, TinyMCE pricing). Neither Strapi plugin documents those paid features, but if you need a vendor to call, that matters.

Limits of Magic Editor X

These come from Editor.js or are not built yet. The README keeps the full list under How Magic Editor X compares.

  • Suggestions and AI review work on whole blocks, not on a few words inside a block.
  • Table cells and columns hold inline text and simple items only, because Editor.js has no nested blocks.
  • There is no crop or rotate inside the editor. The image block opens the file in Strapi's Media Library (Strapi 5.54 and later).
  • Word import leaves out images and keeps a marker in their place; PDF export goes through the browser's print dialog.
  • Touch support is measured in Chromium device emulation, not on real phones or in Safari.
  • It is a young project with one maintainer and few GitHub stars so far.
