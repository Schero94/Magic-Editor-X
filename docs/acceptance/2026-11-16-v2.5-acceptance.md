# Magic Editor X 2.5 acceptance (2026-11-16)

Final build under test: `feat/2.5` at b7e247e (last code change); later commits change only docs, screenshots and this record. Integration ran on the pack of f096b26; b7e247e changed only an attribute of the admin dialogs and two test assertions, and every browser run and both console sweeps ran on the pack of b7e247e. The plugin was packed with `npm pack` (package version 2.4.0 until semantic-release decides 2.5.0) and installed from the tarball into the acceptance host.

Merged into 2.5: the six fixes for the 2.4 known issues, MCP tools (item 5), the entry panel with presence, soft lock, comments and quality, and the homepage widgets (items 1 and 12), insert from another entry and the block clipboard (item 2), private upload providers and dropped files (items 6 and 10), palette colours, superscript/subscript and inline annotations (items 9 and 11), local drafts and lazy start (items 7 and 8), the `@editorjs/embed` 2.7.7 pin for Node 22, and the fixes of this acceptance. Deferred: component blocks (item 3), Live Preview inline editing (item 4), a columns block (item 13) and the session-expiry warning (see the CHANGELOG).

Host: Strapi **5.61.1** (npm `latest` is 5.62.0 since 2026-11-12; see the smoke test below), Node 22.23.1, the union of the eight 2.5 feature hosts on top of the 2.4 union host: content types `api::tag.tag` (no editor field), `api::longform.longform` (20 editor fields and a dynamic zone, no i18n) and `api::glossary-term.glossary-term`; the glossary annotation registered in `register()`; a synthetic `palette`; `presence.softLock`, `lazyInit.enabled`, `mcp.enabled` and Strapi's `server.mcp.enabled` from the environment; a fake private upload provider (`MEX_UPLOAD=private`, files served signed by a fake file server); the pre-2.4 write switch `MEX_PRE24_TITLES`; six seeded admins plus one admin without plugin access. Synthetic data only.

## Bugs found by this acceptance and fixed

- **Private files loaded unsigned first** (be2022d): with a private upload provider every image was requested unsigned before the signed URL replaced it (403 from the storage, console errors, slow first paint), because tools request an image as soon as they set `src`. The field now signs its media before Editor.js renders (one batch, at most 3 s) and `save()` returns the stored URLs (`admin/src/editor/media-signer.mjs`, 4 unit tests). Verified: no 403 in the picker, drop and matrix runs.
- **Entry panel 404 on types without i18n** (be2022d): the Content Manager keeps `plugins[i18n][locale]` in every URL, and `POST /presence` and `GET /entry-summary` refused a locale for such types (empty panel, console errors on `longform`). The locale is now ignored there, as in `checkField` (unit test).
- **DOM nesting error in Settings** (d4b7ef3): the list of hard-to-read colour combinations was rendered inside the Design System Alert's paragraph.
- **401 after logging out from an entry** (f096b26): the panel's last heartbeat ran after Strapi had removed the token. A small middleware tracks the session; the request is skipped after a logout (unit test).
- **Radix description warning on Strapi 5.62** (b7e247e): Design System 2.3.1 (Radix Dialog 1.1.5) warns for every dialog without a description; all plugin Modals pass `aria-describedby={undefined}`, the documented opt-out (contract test).
- **No EBADENGINE on Node 22** (a2d0929): `@editorjs/embed` 2.8.0 requires Node 24; pinned to 2.7.7 with YouTube Shorts and Figma defined by the plugin; `engines.node` declares the Node 22.12 that sanitize-html 2.18 already needed.

Test-only findings, investigated to their cause: scenarios that cached API tokens per port answered 401 after a database was recreated on the same port (the runner now removes them); the media matrix dragged onto the first field while another field was the one that had started (fields start in any order now; the scenario waits for the field it drags onto, 3 / 3 reruns); the picker's Tab budget was too small for a Media Library with the fixtures of every suite; the soft-lock run once counted a session request cancelled by closing the page (`net::ERR_ABORTED`, nothing in the console).
