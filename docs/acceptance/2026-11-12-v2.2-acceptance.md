# Magic Editor X 2.2 acceptance (2026-11-12)

Build under test: branch `feat/2.2`, packed with `npm pack` (the package version stays 2.1.0 until semantic-release sets 2.2.0) and installed from the tarball into an isolated Strapi 5.61.1 host: port 1451 on SQLite, port 1452 on PostgreSQL 16, and the 8-process cluster on PostgreSQL. Random `.env` secrets, outgoing network blocked in every Strapi process (`-r block-egress.cjs`), synthetic admins and content only, the AI provider a local fake server. Host content types as in CONTRIBUTING.md (`summary` with `{ preset: 'basic', requireAlt, maxCharacters: 400, linkTargets: 'internal', disableAi, disableCollaboration, publishGuard }`, `teaser` with `{ preset: 'minimal' }`, `legacy` Blocks, `notes` Markdown, `migrated`).

## Large documents

Chromium (Playwright 1.65), the editor in the Content Manager, document created through the API, typing 25 characters with 20 ms between keys right after the editor is usable:

| Document                | Before (2.1 code path)                                              | After                                                                 |
| ----------------------- | ------------------------------------------------------------------- | --------------------------------------------------------------------- |
| 2,000 blocks, new room  | one long task of 40.6 s during typing; all 2,000 blocks re-rendered | 25 keystrokes in 0.88 s; 1 block re-rendered; ready 2.4 s, live 2.4 s |
| 2,000 blocks, room open | 25 keystrokes in 0.68 s                                             | 0.67 s                                                                |
| 5,000 blocks            | not measured before                                                 | ready 3.8–4.0 s, live 3.8–4.0 s, 25 keystrokes in 0.87–1.22 s         |

Cause: stored content has no tunes while Editor.js writes default tunes on every block, so the first shared state of a new room looked different in every block; each per-block update notifies a mutation watcher on every block (O(blocks²)). Fix in `admin/src/editor/apply-remote.js`. Without live collaboration the same document typed in 0.71 s before the fix.

## Bugs found by this acceptance and fixed

- Internal links lost `data-mex-uid` whenever content was rendered again in the admin (DOMPurify treats the value `api::…` like a URI); the next save stored a plain link. Present since 2.1.
- The Content Manager crashed while formatting Magic Editor X validation errors (`details` without `errors`); errors now carry `details.errors` and show on the field.
- The first character after a Markdown block shortcut could be lost; typing after an inline Markdown mark continued inside the mark.
- The image alternative text overlapped the caption.
- Opening a long document in a new live room froze the tab (see Large documents).
