# Magic Editor X 2.4 acceptance (2026-11-12)

Final build under test: `feat/2.4` at 9690c8a (all 2.4 feature branches merged: stable field identities, tables v2, math and footnotes, range comments with @mentions and notifications, block suggestions, block-aware AI, audit trail, synced source versions, `@` entry trigger and code file names, link check "Run now" and time zone, pasted `<video>`/`<audio>`, AI alt text on private storage, the "More tools" toolbar, the collaboration early-typing fix, Strapi AI translation and Releases readiness guards) plus the two fixes of this acceptance. Later commits change only screenshots and this record. The plugin was packed with `npm pack` (package version 2.3.1 until semantic-release decides 2.4.0) and installed from the tarball into one isolated Strapi 5.61.1 host: port 1461 on SQLite, port 1462 on PostgreSQL 16 (own cluster on 5561), and the 8-process cluster on PostgreSQL. Node 22.23.1, Playwright 1.65 (Chromium), React 18.3.1, styled-components 6.6.0 and react-router-dom 6.30.6 deduped once each. Random `.env` secrets (mode 600), outgoing network blocked in every Strapi process (`-r block-egress.cjs`), synthetic admins and content only; the AI provider, LanguageTool, link targets, media server, private image storage and SMTP server are local fakes on 127.0.0.1.

Host: the union of the eleven 2.4 feature hosts, recorded in CONTRIBUTING.md (6e6e196, 08617eb): content types of 2.3 plus `groups`, the dynamic zone with `blocks.text-section`, `blocks.quote-card` and `blocks.group`; plugin config with `ai.altText.allowPrivateOrigins` (1590), `uploads.allowPrivateOrigins` (1587) and `maxMediaBytes` 1 MiB, `audit`, the link schedule time zone (`MEX_LINK_TZ`), `comments.notifications.email` (`MEX_MENTION_EMAIL`), the nodemailer provider pointing at a fake SMTP server on 1591; bootstrap rows for the private-storage test (`MEX_PRIVATE_FILES=true`, integration only) and the legacy Settings blocks `toc` and `math` (`MEX_LEGACY_BLOCKS=true`); six seeded admins (editor, author, reviewer, reader, writer, outsider) with the suggestion permissions; admin login limit 60.

## Bugs found by this acceptance and fixed

- Low contrast in code blocks (c49c087): Strapi's Blocks field loads `prism-solarizedlight` globally, and tokens the code block did not colour itself took that theme's colours; Python builtins such as `str` and `sum` were cyan `#2aa198` at 2.93:1 on the light code background (`s23-matrix`, 4 to 8 items at every light width; also present in 2.3.1). Every token now gets a base colour with higher specificity than a global theme; regression test in `tests/admin-source-contract.test.mjs`. After the fix `s23-matrix` reports no low contrast on either database.
- Leaving focus mode with its "Leave focus mode" button dropped keyboard focus to `<body>` (9690c8a): the button unmounts with focus mode. Exit buttons of tools that do not move focus themselves now return focus to the More tools trigger; regression test in `tests/ux-24.test.mjs`; verified in the browser (focus on `mex-tools-menu`).
- CONTRIBUTING.md lacked the union of the 2.4 host setups, and its login limit of 20 was too low for 24 test files (the first full run hit 429 on the Super Admin login in the last files, because Strapi counts logins per user and IP): recorded with limit 60 (6e6e196, 08617eb).

## Not verified

- Review workflows (deferred in 2.4), Content Releases and Strapi AI translations need an Enterprise or Growth plan; they were proven in-process with Strapi's own functions on both databases, not through their UIs.
- Mention e-mails went to a local fake SMTP server only; the e-mail text is English for every recipient (documented limit).
- Chromium only: no Firefox or Safari run, and browsers without the CSS Custom Highlight API (no comment highlight) were not tested.
- The Content-Type Builder scenario (`s22-ctb`, develop mode) was not run; the per-admin comment rate limit across processes has no test.
- The benchmark ran on a10732d; the later changes touch only admin styles and the toolbar.
- `tests/docs.test.mjs` fails until the docs branch (README routes/config/RBAC, `llms-full.txt`) is merged.
