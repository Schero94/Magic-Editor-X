# Magic Editor X 2.6 acceptance (2026-11-18)

Final build under test: `feat/2.6` at b886aca (every 2.6 branch merged: component blocks, columns, Live Preview, session expiry, plus the socket/session binding and the caret fix of this acceptance). The fixes of the independent review are at b13be07 and were verified on that pack (section "Review fixes"). The plugin was packed with `npm pack` (package version 2.5.3 until semantic-release decides 2.6.0) and installed from the tarball into the acceptance host; the install is compared byte for byte with the tarball.

Host: Strapi **5.62.0** (npm `latest`, checked 2026-11-17), Design System and icons 2.3.1, Node 22.23.1, PostgreSQL 16.15, on its own ports (2610-2612, cluster 2700-2718, PostgreSQL 5626), new random secrets, outgoing connections blocked (`block-egress.cjs`), synthetic data only. It is the 2.5 union host plus the 2.6 components `blocks.cta` and `blocks.media-card` and the article `body` option `allowedComponents: "blocks.cta,blocks.retired"` (CONTRIBUTING.md). Feature helpers used their own clones of this host (`host-cols`, `host-sess`, `host-prev` with Strapi's preview enabled and a synthetic front end).

The 2.5 fix for component blocks (patches and text rebase) was reviewed before shipping. One window was still open: a keystroke typed after the field's last push and before a room snapshot was applied was overwritten by the snapshot, and the editor then recorded its own serialisation as the diff base, so the keystroke never reached the room. A replica test reproduces the loss; 2.6 keeps the room's values per block (`synced`), merges unpushed edits onto snapshots and records the room's values as the diff base.

## Bugs found by this acceptance and fixed

- **Component blocks lost a keystroke in a live room** (ae3fc41): see "Proof of no lost edits".
- **A live socket outlived its admin session** (7b0e173): a socket opened before the session was revoked kept accepting edits until the browser paused it. The token now carries the session id; the handshake, every update (at most every 5 s per socket) and the periodic re-check refuse ended sessions with `SESSION_ENDED`, following Strapi's session rotation to the newest session of the family. `tests/integration/session-socket.test.mjs`: 1/3 before, 3/3 after, both databases.
- **Typing after a pause landed at the start of the paragraph** (bbe3789, since 2.5.0): Editor.js 2.31 clears the document selection whenever an instance starts, and lazily started fields did that while someone typed in another field. The caret is now kept (`selection-keeper.mjs`). Browser: 6/6 wrong before, 0/28 after; the session scenarios' own output showed the same reordering before the fix.
- **Columns: list item edits could land in the wrong item** (columns branch): the Yjs mapping now matches list items that carry an id by that id.
- Test-only: macOS `End` scrolls the page instead of moving the caret in Chromium; the columns stress harness placed the caret directly after an early run marked two rounds as lost although every character was stored.
