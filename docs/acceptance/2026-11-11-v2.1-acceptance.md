# Magic Editor X 2.1 acceptance (2026-11-11)

Build under test: branch `feat/collab-2.1`, packed with `npm pack` (the package version stays 2.0.0 until semantic-release sets 2.1.0) and installed from the tarball into isolated Strapi 5.61.1 hosts: 1431 (SQLite), 1432 (PostgreSQL 16), 1441 (a database written by 1.5.1, upgraded straight to 2.1), and the 8-process cluster on PostgreSQL. Random `.env` secrets per host, outgoing network blocked in every Strapi process (`-r block-egress.cjs`), synthetic admins and content only. The AI provider is a local fake server.

Note on large documents: Editor.js 2.31 finishes per-block set-up (`requestIdleCallback` in its `Block` constructor) in the background after rendering; with 2,000 blocks this takes about 35 s in headless Chromium. The editor is usable during that time; it is core behaviour, not plugin code.

### 2.1 additions

`s-addendum` (12 / 12 on the upgraded 1.5.1 host): the Content Security Policy notice lists the blocked embed sources, the copy button puts the `strapi::security` snippet on the clipboard with a success toast, the notice has no overflow at 390 px, blocked embeds and external images show the placeholder with a "How to allow it" link and do not mark the form as changed, the internal-link picker finds an entry by title and inserts `<a href="/articles/<documentId>" data-mex-uid data-mex-document-id data-mex-locale>`, and the link survives the server sanitiser on save.

### Migration from 1.5.1

The 1.5.1 database (JSON strings, plain text values, nested lists, checklists, tunes, a component field, a single type, a second locale, Yjs-only snapshots, a custom block with a script in its SVG icon and template) upgraded directly to 2.1: 17 / 17. This gate found that opening 1.x content marked the form as changed (Editor.js normalises some 1.x blocks while rendering and the block-menu save reported it); fixed in `fix(admin): opening 1.x content no longer marks the form as changed`.

### Console

No console errors from plugin code. Remaining messages also appear on native Content Manager pages: 404 for `/content-manager/preview/url/…` and `/i18n/ai-localization-jobs/…` (Strapi core), the styled-components `attribute` prop warning (Strapi core), `ERR_INTERNET_DISCONNECTED` while the offline test runs, and CSP refusals for YouTube frames and external images, which the new placeholder and settings notice now explain.
