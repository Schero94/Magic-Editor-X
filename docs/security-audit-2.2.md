# Magic Editor X 2.2 security review: new surfaces

Scope: everything 2.2 adds or changes on top of 2.1.0 (`main` at 10330e5): field presets (save middleware, realtime guard, AI and session routes), paste cleanup and the converters, the migration service and CLI, the renderers, the JSON Schema and types, named versions and the version diff, the quality checks (lint, `POST /quality/links`, publish guard), image alternative text, find and replace, Markdown shortcuts, block selection actions, internal-link resolution and the room compaction of the collaboration server. Method: threat model per surface and actor (anonymous, admin without the plugin actions, read-only reviewer, editor, an editor with a modified client, a hostile clipboard or source document, a hostile stored value read by a frontend), code review, then tests: unit and property tests (`npm test`), the integration suite against Strapi 5.61.1 on SQLite and PostgreSQL 16 (`tests/integration/*.test.mjs`, 28 tests), the 8-process cluster run (18 checks) and browser acceptance. Synthetic accounts and data only.

## Unchanged controls re-checked

RBAC on every new route (`admin::isAuthenticatedAdmin` + `admin::hasPermissions`), strict bounded zod schemas, Content Manager access checks with 404 for denied documents, no secrets in responses, no content or personal data in logs, maintained dependencies only (`marked` 18 and `htmlparser2` 12 were added after checking their release activity; both are bundled into the server build), `npm audit --omit=dev`: 0 vulnerabilities.

## Residual risks

- Field presets apply to Magic Editor X fields only; Strapi's own Content API permissions still decide who may write at all.
- The external link check, when turned on, reveals to editors whether a public URL answers; it never reaches private addresses.
- `links.resolveHrefs` is a server helper without admin permission checks by design; call it only for content the caller may already see.
- Focus mode dims the other blocks below 4.5:1 on purpose; the focused block keeps full contrast.
