# Magic Editor X 2.0 security audit

Scope: server (`server/src`), shared code (`shared/`), admin (`admin/src`), release pipeline. Baseline: 1.6.0 (`main` at 0c8be12; same code as 42c9ae1, which this audit read). Method: route inventory, threat model per route (workbench skill `strapi-plugin-security`), code review, then tests against a real Strapi 5.61.1 host (SQLite and PostgreSQL) and an adversarial re-attack pass. Synthetic data only; no live provider was called.

## Controls in 2.0

- **Authorisation:** `admin::isAuthenticatedAdmin` + `admin::hasPermissions` on every route; entry checks through the Content Manager permission checker; 404 for "not yours".
- **Input:** zod strict schemas with bounds; editor JSON limited to 5 MiB, 5000 blocks, depth 24.
- **Output:** settings never contain secrets (`hasApiKey`, `apiKeyUnreadable` flags); `Cache-Control: no-store` on settings, sessions and exports.
- **SSRF:** link preview and image by URL allow only public addresses; the AI base URL must be public https unless the owner sets `ai.allowPrivateBaseUrl` in config (not in the UI); AI requests follow no redirects. Changing provider or base URL requires the key again, so a stored key cannot be redirected to another host.
- **Secrets:** AES-256-GCM, versioned format, HKDF subkeys, key from `MAGIC_EDITOR_X_ENCRYPTION_KEY` (min. 32 chars); without it no key is stored.
- **Rate limits:** AI per admin and process (`ai.requestsPerMinute`); keyed by admin id, not by IP or header.
- **XSS:** shared sanitize policy per block type; inline HTML allowlist; URL schemes http/https/mailto/tel and relative; no protocol-relative URLs; `rel="noopener noreferrer"` on new-tab links; admin previews use inert `DOMParser` and text nodes.
- **ReDoS:** bounded regexes; adversarial time-budget tests.
- **Privacy:** presence stores display names only while the user is in the room; rooms are deleted 30 minutes after the last activity; AI text is never logged.
- **Supply chain:** unmaintained packages removed; actions pinned by SHA; `npm ci --ignore-scripts`; Dependabot with cooldown; `npm audit --omit=dev` 0.

## Adversarial re-attack pass

Attempts against the 2.0 build on the acceptance host, each with the result:

| Attack                                                                                                     | Result                                             |
| ---------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| Join a room of a document owned by another author (Author role, is-creator condition)                      | 404                                                |
| Replay a used session token; forge a signature; connect with a foreign `Origin`                            | refused (`INVALID_TOKEN`, handshake rejected)      |
| Viewer sends a Yjs update                                                                                  | `{ ok: false, code: 'READ_ONLY' }`, nothing stored |
| Store `<script>`, `onerror`, `javascript:` through the Content Manager API                                 | removed on save                                    |
| Store deeply nested JSON (40 levels)                                                                       | 400                                                |
| Custom block with reserved name, extra privileged key, script in SVG/template                              | 400 / sanitised                                    |
| Image upload with SVG bytes named `.png`; PDF with executable bytes                                        | 400                                                |
| Image by URL / link preview to 127.0.0.1, `[::1]`, 169.254.169.254, localhost, userinfo URL, `javascript:` | 400                                                |
| AI: unknown action, unsupported language, oversized text, no permission, burst of requests                 | 404 / 400 / 413 / 403 / 429                        |
| Change AI provider to a new host without re-entering the key                                               | 400                                                |
| Read settings as Editor role                                                                               | 403                                                |

Re-attack findings that led to fixes during this pass: route params were passed to strict schemas unfiltered (an extra router key caused a 400 on `GET /history/:id`); fixed by picking `id` explicitly.

## Residual risks

- Rate limits and the collaboration poller are per process; with N processes the AI limit is effectively N × `requestsPerMinute`.
- Concurrent edits of the same non-text value (for example two people changing the same table at once) resolve last-writer-wins per data key; text fields merge character by character.
- `rawHtml: 'allow'` stores raw HTML as typed; frontends must treat it as trusted.
- Editor.js injects inline styles; the Strapi admin's default CSP (`style-src 'unsafe-inline'`) allows this.
