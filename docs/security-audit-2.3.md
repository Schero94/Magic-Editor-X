# Magic Editor X 2.3 security review: new surfaces

Scope: everything 2.3 adds or changes on top of 2.2.0 (`main` at fd9b014): the render tree and the React/Vue components, the Content API `?mex=` output and the GraphQL fields with reference resolution, the custom block SDK, the gallery/video/audio blocks and the focal point, the table of contents and mentions, templates and patterns, the in-field preview, synced blocks, block comments, the scheduled external link check, AI alternative text and whole-field AI actions, the LanguageTool grammar check, and the version diff fix. Method: threat model per surface and actor (anonymous, a Content API token or users-permissions role with limited permissions, an admin without the plugin actions, a read-only reviewer, an editor, an editor with a modified client, a hostile stored value read by a frontend, a hostile provider answer), code review, then tests: unit and property tests (`npm test`), the integration suite against Strapi 5.61.1 on SQLite and PostgreSQL (`tests/integration/*.test.mjs`), the multi-process cluster run and browser acceptance. Synthetic accounts and data only.

## Unchanged controls re-checked

RBAC on every new admin route (`admin::isAuthenticatedAdmin` + `admin::hasPermissions`), strict bounded zod schemas, Content Manager access checks with 404 for denied documents, no secrets in responses, no content or personal data in logs, maintained dependencies only (`vue` added as an optional peer and development dependency only), `npm audit --omit=dev`: 0 vulnerabilities.

## Residual risks

- Without `?mex`, Content API responses still contain the stored hrefs (which can carry a target's slug) and embedded-entry snapshots, as in 2.2.
- `status=draft` resolves draft targets for any caller with `find` on the target type, matching what Strapi already allows those callers.
- Custom `text`/`markdown` functions of SDK blocks return strings; escape helpers are provided but not enforced.
- Comment rows deleted around the Document Service (raw SQL, `db.query`) leave orphans; the per-field comment cap is a soft check.
- Any `access` user can list the templates in scope for a field; template creator names are snapshots and stay after the admin is deleted.
- With an owner-listed private origin, editors can see the HTTP status codes of that host.
- Synced sources have no Draft & Publish: an edit is live in published output immediately; old field versions render the current source.
- Translated text is only as faithful as the provider's answer; the editor reviews it in the preview.
