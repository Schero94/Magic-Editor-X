# Magic Editor X 2.6 security review: new surfaces

Scope: everything 2.6 adds or changes on top of 2.5.3 (`main` at abad4c6): component blocks (Content-Type Builder components as blocks, their form, save checks, output and live rooms), the columns block (a constrained cell model with nested items inside one block), the Live Preview additions (renderer block attributes, `?mexBlockIds`, click-to-locate by URL and by `postMessage`), the session-expiry detection, the binding of collaboration sockets to the admin session, the caret keeper around editor starts, and the change to list item matching in the Yjs mapping. Reviewed against the installed Strapi 5.62.0 source and the workbench security rules (route authz and RBAC, IDOR, mass assignment, input bounds, ReDoS, injection, XSS, CSRF, secrets, rate limits, privacy, logging, supply chain).

## Unchanged controls re-checked

No new admin route and no new permission action in 2.6. The caret keeper (`selection-keeper.mjs`) only re-adds a range the user already had in a focused field, inside the same document; it reads no content (component blocks, columns and click-to-locate reuse existing routes; `GET /config` adds `data.components`, schema only, no content, behind `config.get`). Strict bounded zod schemas, Content Manager access through `services/access.js` with 404 on denial, no content, tokens, URLs with queries or personal data in logs, outgoing requests only through `utils/url-security.js` (2.6 adds none), synthetic data in tests and screenshots. `npm audit --omit=dev`: see the acceptance record; no new runtime dependency.

## Residual risks

- Component blocks support scalar attributes only. Media, relations and nested components are refused because they need permission checks and population per caller; a later version that adds them needs its own review.
- Two people typing in the same component attribute at the same time keep both texts, but the local caret jumps to the end of that input (a controlled input moves the caret when its value is replaced).
- Moving a column item to another column (fewer columns, cut and paste) is a delete plus an insert: an edit someone makes in that item at that moment is lost, the limit the 2.5 spike measured. The editor offers no per-item move between columns.
- A table of contents does not list headings inside columns.
- Strapi's Live Preview double-click popover works on a community host in 5.62.0 without a licence check in the code; Strapi documents it as a paid feature. Magic Editor X does not depend on it.
